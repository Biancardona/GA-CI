# Proyecto de Integración Continua

Este repositorio se utilizará para realizar una práctica de Integración Continua con GitHub Actions.

## Objetivo

Comprobar que GitHub Actions ejecute automáticamente un workflow cada vez que se realice un cambio en la rama main.

## Prueba de Integración Continua

Modificación realizada para comprobar la ejecución automática de GitHub Actions.
